# solsmod-releases

Release builds of **Solsmod-26.2-fabric** (Minecraft 26.2, Fabric).

- `jars/` holds every version.
- `latest.json` points at the newest one. The mod reads it on launch and auto-updates itself (the new version installs when the game or server closes).

To install manually, download the newest jar from `jars/` and put it in your `mods` folder (remove or disable the old one).
